# Fruits and Vegetable Classification

## Project Overview
This project focuses on classifying fruits and vegetables using Machine Learning and image processing techniques.

## Dataset
Fruits-360 Dataset

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- OpenCV

## Project File
- `fruits_and_veg (1).ipynb`

## Objective
To build a machine learning model that can identify and classify different fruits and vegetables based on image features.
